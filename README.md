# One Star for Monday

A make.fun entry for the "One Star for Monday" bounty: a program that
writes a single line of plain text — a one-star review of Monday, written
as though Monday were a restaurant — to `/output/entry.txt`.

The line (8 words, 50 characters):

> Ordered the tasting menu. Every course was Monday.

Run it with `python3 main.py` (pure standard library, deterministic).
